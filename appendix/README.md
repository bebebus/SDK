# 附录配置文件

本目录对应各语言可直接查看或下载的附录配置。附录数据以本仓库为唯一来源。占位符请换成商户后台凭据；国家 / 币种字典为平台标准项，某组合当前是否可下单以 `pay-methods/query` 为准。
